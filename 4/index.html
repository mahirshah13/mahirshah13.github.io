Project 4: Neural Radiance Fields (NeRF)

3D Scene Reconstruction and Neural Field Representations

Project Overview

This project explores Neural Radiance Fields (NeRF), a powerful technique for representing 3D scenes using neural networks. The project is divided into two main parts: first, we learn to work with neural fields in 2D by fitting an MLP to represent images, then we apply camera calibration techniques to prepare data for full 3D NeRF reconstruction.

Part 0: Calibrating Your Camera and Capturing a 3D Scan

In this part, we capture a 3D scan of a coffee tumbler using ArUco tags for visual tracking and camera calibration. The process involves camera calibration, object scanning, pose estimation, and dataset preparation for NeRF training.

Part 1: Neural Field (2D Image)

Before tackling 3D NeRF, we start with a 2D neural field that learns to represent an image. This involves training a Multi-Layer Perceptron (MLP) with positional encoding to map 2D pixel coordinates to RGB colors.

1. Model Architecture

Network Architecture

  • Type: Multi-Layer Perceptron (MLP)
  • Layers: 3 (2 hidden layers + 1 output layer)
  • Hidden Width: 256 (default) / 64 (variant)
  • Activations: ReLU (hidden layers), Sigmoid (output)
  • Input Dimension: 42 (after positional encoding)
  • Output Dimension: 3 (RGB)
  • Total Parameters: 143,363 (L=10, width=256)

Training Hyperparameters

  • Learning Rate: 1e-2
  • Optimizer: Adam
  • Loss Function: MSE (Mean Squared Error)
  • Batch Size: 10,000 pixels per iteration
  • Iterations: 2000
  • Metric: PSNR (Peak Signal-to-Noise Ratio)

Key Findings

  • Higher PE Frequency (L=10): Captures more detail and produces sharper edges
  • Wider MLP (256): Better reconstruction quality and capacity to represent complex patterns
  • Lower L + Low Width: Results in blurred output due to limited model capacity
  • Best Combination: L=10 with Width=256 provides optimal balance of detail and quality
  • Positional Encoding Importance: PE enables the network to learn high-frequency details that would be difficult to capture with raw coordinates alone

Part 2: Neural Radiance Field (3D NeRF)

Building on the 2D neural field from Part 1, we now implement a full 3D Neural Radiance Field (NeRF) that learns to represent a 3D scene from multiple 2D views. This involves ray generation, point sampling along rays, and volume rendering to synthesize novel views.

Key Implementation Highlights

  • 3D Scene Representation: NeRF learns a continuous volumetric representation from just 2D images
  • View-Dependent Effects: Conditioning on ray direction enables modeling of specular highlights and reflections
  • Volume Rendering: Proper alpha compositing with transmittance produces photorealistic images
  • Stratified Sampling: Perturbed sampling points along rays help capture fine details
  • Novel View Synthesis: Trained NeRF can render views from camera positions never seen during training
  • Target Achievement: Successfully reached 23+ PSNR on validation set, demonstrating high-quality 3D reconstruction

Part 2.6: Training with My Own Data

Using the coffee tumbler dataset captured and calibrated in Part 0, I trained a NeRF to reconstruct the 3D scene. This involved adapting the hyperparameters and scene bounds to work with real-world captured data rather than the synthetic Lego dataset.

Hyperparameter Adjustments

Key Changes for Real Data

  • Scene Bounds: Adjusted near and far planes to match the real-world scale (near=0.02, far=0.5 instead of 2.0 and 6.0)
  • Samples per Ray: Initially trained with 32 samples for debugging, then increased to 64 for final results
  • Image Resolution: Ensured images were appropriately sized and intrinsics matrix matched the resolution
  • Training Duration: Extended training to ~2000 iterations to achieve good reconstruction quality
