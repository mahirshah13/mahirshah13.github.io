A.3 Warp the Images (Inverse Mapping)

Given H that maps source→target (p' = Hp), I create an output canvas, iterate over target pixels, map each location back with H⁻¹ into the source, and sample using bilinear interpolation. I also produce an alpha mask to signal valid samples.

Process:

Canvas sizing: Transform the four source corners through H to get a tight bounding box, or accept a fixed output shape.

Grid back-projection: Make a meshgrid over destination pixels, convert to homogeneous, and map back with H⁻¹ to get subpixel source coordinates.

Bilinear interpolation: Weighted 4-neighborhood sampling provides smoother results than nearest-neighbor by averaging surrounding pixel values, reducing aliasing artifacts and creating more natural-looking warped images.

Validity mask: Mark pixels whose back-projected coordinates fall inside the source and are finite; return this as alpha for blending.

Rectification:

I click four corners of a planar rectangle in top left → top right → bottom right → bottom left order. I estimate the target width/height from the clicked edge lengths, define a canonical rectangle [0,0] to [W-1,H-1], solve H = computeH(src, dst), and inverse-warp. This validates both computeH and the warpers.

Interpolation Quality:

Bilinear interpolation produces smoother, sharper, and more appealing results compared to nearest-neighbor sampling. By averaging the four surrounding pixels with distance-weighted coefficients, bilinear interpolation eliminates the pixelated artifacts and jagged edges that characterize nearest-neighbor sampling, resulting in more natural-looking warped images with better visual continuity.

Blending Procedure:

  • Computed warped bounds: Found how far each image moved after applying its homography so the final canvas could fit all warped images.
  • Translated images to positive coordinates: Built a translation matrix so all warped images started within the mosaic canvas (no negative coordinates).
  • Created smooth alpha masks: Generated a cosine falloff weight from 1 (center) to 0 (edges) for smooth blending between overlapping images.
  • Warped images and alpha masks: Used my bilinear warping function to project each image (and its alpha mask) into the mosaic coordinate frame.
  • Applied feather blending: Combined all warped images by weighted averaging with their alpha masks to avoid seams and brightness drops.
  • Computed final mosaic: Determined the canvas size from warped bounds, translated and warped all images, and blended them using feathering to produce a seamless mosaic.

I also experimented with different alpha values for smoother transitions. Feather blending worked really well, so I didn't try Laplacian pyramid blending, but it would be cool to explore next!

B.1 Harris Corner Detection

This section implements Harris Interest Point Detection and Adaptive Non-Maximal Suppression (ANMS) for detecting robust corner features in images.

Analysis:

Harris Interest Points: The Harris detector computes a corner strength function based on the harmonic mean of eigenvalues from the gradient structure tensor:

fHM(x, y) = det Hl(x, y) / tr Hl(x, y) = λ1λ2 / (λ1 + λ2)

Interest points are detected where this corner strength is a local maximum in a 3×3 neighborhood and exceeds a threshold. This produces numerous corner detections throughout the image.

Adaptive Non-Maximal Suppression (ANMS): To obtain a uniformly distributed set of keypoints, ANMS filters corners by retaining only those that are locally maximal within their neighborhood. Each corner's suppression radius is determined by the distance to its nearest stronger neighbor. By selecting corners with the largest suppression radii, we ensure feature points are spread evenly across the image, avoiding clustering and providing better coverage for subsequent matching.

Analysis:

For each corner point identified by ANMS, I extract a 40×40 pixel window centered at the keypoint. This larger window is then downsampled to an 8×8 descriptor by sampling every 5th pixel, which captures the blurred local structure around the corner. The resulting 64-dimensional descriptor is flattened and bias/gain normalized by subtracting the mean and dividing by the standard deviation. This normalization provides invariance to affine intensity changes, making the descriptors robust to lighting variations between images.

Analysis:

The feature matching algorithm uses Lowe's ratio test to identify reliable correspondences between image pairs. For each descriptor in the first image, I compute the squared Euclidean distance to all descriptors in the second image. I then find the two nearest neighbors: the best match and the second-best match. A match is accepted only if the ratio of the best distance to the second-best distance is below a threshold of 0.7, indicating that the best match is significantly better than the second-best. This ratio test effectively filters out ambiguous matches and reduces false positives, as distinctive features will have a clear best match while non-distinctive regions will have similar distances to multiple features.

Sharpness Comparison:

The automatic stitching produced a noticeably sharper result compared to the manual stitching. This is likely because manual point correspondence selection can introduce small human errors in the mappings, leading to slight misalignments that cause blurriness in the blended regions. The RANSAC-based automatic approach, by optimizing over many feature matches and selecting the best homography, achieves more precise alignment and thus a crisper final mosaic.

RANSAC Implementation:

I implemented 4-point RANSAC from scratch to compute robust homography estimates. The algorithm works by randomly selecting 4 feature matches, computing a homography from those points, and then counting how many of the remaining matches are consistent with that homography (inliers). This process repeats for many iterations, keeping track of the homography with the most inliers. For each candidate homography, I project points from one image to the other and measure the reprojection error. Matches with error below a threshold are considered inliers. After testing all iterations, the best homography is recomputed using all the inliers, which provides a robust estimate even in the presence of outliers from incorrect feature matches.

Multi-Image Stitching:

The Berkeley Campus mosaic demonstrates the power of automatic stitching with 5 images. The algorithm handled the sequential alignment efficiently with good runtime performance, producing a seamless panorama. This would have been significantly more challenging with manual calibration, where selecting dozens of correspondence points across multiple image pairs would be tedious and error-prone. The automatic approach scaled well and delivered impressive results.
