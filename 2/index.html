Project 2: Fun with Filters and Frequencies

2D Convolutions, Filtering, and Image Processing

Project Description

This comprehensive project explores 2D convolutions, filtering, and frequency domain image processing techniques. I implement convolution from scratch using both four-loop and two-loop approaches, comparing performance with optimized libraries. The project covers finite difference operators for edge detection, Gaussian and Derivative of Gaussian (DoG) filters, and explores frequency domain techniques including unsharp masking for image sharpening. I create hybrid images that change interpretation with viewing distance, blending high and low frequency components from different sources. Additionally, I implement Gaussian and Laplacian image pyramids for multiresolution blending, creating seamless composites like the legendary "Oraple" (apple + orange) and dynamic day-to-night transitions. Throughout, I analyze computational complexity, threshold selection, and perceptual effects of various filtering operations on real images including selfies, architectural landmarks, and natural scenes.

Runtime Analysis:

4-loop implementation: O(H×W×k_h×k_w) where H,W are image dimensions and k_h,k_w are kernel dimensions.

2-loop implementation: Same complexity but with better memory access patterns, using numpy broadcasting for inner computation.

scipy.signal.convolve2d: Highly optimized implementation using compiled C code, Fast Fourier Transform (FFT) for large kernels, and efficient memory management.

Performance observations: For small images like mine, the 4-loop version was actually faster than the 2-loop version, likely because the overhead of creating numpy views in the 2-loop case offsets the benefits for small image sizes. For larger images, the 2-loop version becomes faster. Both implementations are significantly slower than scipy regardless, likely because scipy is compiled to use C++ for the inner loops.

Threshold Selection Analysis:

I tested several threshold values for binarizing the gradient magnitude image. A threshold of 0.5 provides a good balance between preserving important edge details while suppressing noise. Higher thresholds (0.6-0.8) removed too many fine edges, while lower thresholds (0.2-0.3) introduced excessive noise. The choice of 0.5 maintains the major structural features of the cameraman image while creating clean, well-defined edges.

Part 2.1: Image "Sharpening"

Pick your favorite blurry image and get ready to "sharpen" it! We will derive the unsharp masking technique. Remember our favorite Gaussian filter from class. This is a low pass filter that retains only the low frequencies. We can subtract the blurred version from the original image to get the high frequencies of the image. An image often looks sharper if it has stronger high frequencies. So, lets add a little bit more high frequencies to the image! Combine this into a single convolution operation which is called the unsharp mask filter.

Unsharp Mask Technique:

The unsharp mask filter enhances image sharpness by emphasizing high-frequency components through a three-step process:

Step 1: Apply Gaussian blur to create a low-pass filtered version of the image, preserving only smooth, gradual variations.

Step 2: Subtract the blurrified image from the original to extract high-frequency details (original - low-pass = high frequencies remaining).

Step 3: Add amplified high-frequency components back to the original image, making edges and textures more pronounced while maintaining overall image structure.

Part 2.2: Hybrid Images

The goal of this part is to create hybrid images using the approach described in the SIGGRAPH 2006 paper by Oliva, Torralba, and Schyns. Hybrid images are static images that change in interpretation as a function of the viewing distance. The basic idea is that high frequency tends to dominate perception when it is available, but, at a distance, only the low frequency (smooth) part of the signal can be seen. By blending the high frequency portion of one image with the low-frequency portion of another, you get a hybrid image that leads to different interpretations at different distances.

Process Overview: Derek + Nutmeg Hybrid

Creating hybrid images involves low-pass filtering one image (to capture low frequencies) and high-pass filtering another image (to capture high frequencies), then combining them. For the Derek and Nutmeg example, Derek's image provides the low frequencies (visible at distance) while Nutmeg's image provides the high frequencies (visible up close).

Part 2.3: Gaussian and Laplacian Stacks

The Gaussian stack was generated by repeatedly applying a Gaussian blur to the image, while the Laplacian stack was constructed by subtracting successive Gaussian levels.

Apple Stacks - Gaussian (Top) and Laplacian (Bottom)

Apple Stack Analysis:

Top row (Gaussian L0–L5): Successive blurring reduces detail while keeping overall structure.

Bottom row (Laplacian L0–L5): Isolates band-pass features at each level, emphasizing edges and textures of the apple.

Orange Stacks - Gaussian (Top) and Laplacian (Bottom)

Orange Stack Analysis:

Top row (Gaussian L0–L5): Progressive smoothing removes high-frequency surface details of the orange.

Bottom row (Laplacian L0–L5): Captures fine-to-coarse edge details, highlighting texture differences across scales.
